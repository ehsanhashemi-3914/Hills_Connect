# هیلز کانکت — شبکه‌سازی و مچینگ اعضای پروژه هیلز (نسخه‌ی نمایشی)

بخش شبکه‌سازی اعضای هیلز: پروفایل حرفه‌ای، مچینگ هوشمند بر اساس مهارت و نیاز، فرصت‌های همکاری، رویدادها و پنل مدیریت برای تیم هیلز. **پیام‌رسان نیست**؛ ارتباط بعد از قبول درخواست همکاری، از راه‌هایی که خود اعضا ثبت کردن انجام می‌شه.

طراحی و توسعه: **سید احسان هاشمی** — [سایت شخصی](https://my-personal-site-rho-one.vercel.app/) · [تلگرام](https://t.me/EhsanHashemi_1453)

## امکانات

- **ورود و آنبوردینگ چهارمرحله‌ای:** معرفی، مهارت‌ها، «دنبال چی هستی؟»، پلتفرم‌ها و راه ارتباطی
- **خانه:** مچ‌های امروز، درصد تکمیل پروفایل، فرصت‌های مناسب، رویدادها، اعضای ویژه، اطلاعیه‌ی تیم هیلز
- **کشف و مچ:** کارت‌های کشیدنی (راست = درخواست همکاری) + جستجوی هوشمند به زبان محاوره («تدوینگر ریلز در تهران»)
- **فرصت‌ها:** همکاری، استخدام، اسپانسری، استودیو؛ با درصد تناسب هر فرصت با مهارت‌های کاربر
- **شبکه‌ی من:** درخواست‌های دریافتی و ارسالی و هم‌تیمی‌ها؛ راه ارتباطی فقط بعد از قبول نمایش داده می‌شه
- **پروفایل:** تأیید مهارت توسط بقیه، نمونه‌کار، پلتفرم‌ها و فیلدهای سفارشی
- **پنل مدیریت** (از پروفایل ← «پنل مدیریت»): داشبورد آمار، عرضه و تقاضای مهارت‌ها، مدیریت اعضا (تأیید، ویژه، منتور، تعلیق، خروجی اکسل)، تأیید فرصت‌ها، اطلاعیه، لانچ‌ها، فیلدهای سفارشی پروفایل

## اجرا

```bash
npm install
npm run dev
```

آدرس: <http://localhost:5174>. ورود با هر شماره موبایل و کد **۱۲۳۴۵**.

همه‌چیز داخل مرورگر اجرا می‌شه (بدون سرور) و داده‌ها در localStorage همون مرورگر می‌مونن. هر ۱۲ ساعت دمو تازه می‌شه؛ از «پروفایل ← شروع دوباره‌ی دمو» هم می‌شه دستی ریستش کرد.
